## 2. 웹 스택 후보

### 2.1 확인된 사실

| 서비스 | 무료 한도 (공식 페이지) | DayOS에 주는 의미 |
|---|---|---|
| **Supabase** (DB + 로그인) | DB 500MB/프로젝트, 인증 월 5만 MAU, 파일 1GB, 활성 프로젝트 2개, **1주 비활동 시 일시정지** | 개인·소규모에는 충분. 일시정지되면 알림도 멈춘다 |
| Supabase Row Level Security | 표에 정책을 걸어 "내 행만 조회/수정" 규칙을 DB가 강제. 공식 문서는 **모든 노출된 표에서 RLS를 직접 켜라**고 안내(자동 아님) | 사용자별 데이터 분리를 앱 코드가 아니라 DB가 보장. 단, 표마다 켜는 것을 잊으면 뚫린다 → 테스트 필요 |
| Supabase Cron | 주기를 초 단위부터 설정 가능, HTTP/Edge Function 호출 가능. **무료 플랜 제공 여부는 문서에 명시 없음 → 미확인** | 알림 예약의 후보. 무료 가능 여부를 먼저 확인해야 함 |
| Supabase Edge Functions | 무료 월 50만 호출 | 알림 발송·AI 호출 중계 후보 |
| **Vercel Hobby** | 무료, **비상업적 개인용 한정**. 함수 월 100만 호출, 대역폭 100GB. **cron은 하루 1번, 시각 ±59분** | 개인 MVP엔 가능. 상업 서비스·정밀 알림엔 부적합 |
| Vercel Pro | 개발자 좌석 월 $20 (공식 페이지) | 공개 서비스용 비용 기준 |
| Cloudflare Workers Free | 하루 10만 요청, 요청당 CPU 10ms, **Cron Trigger 5개** | 스케줄 가능. 상업 이용 허용 여부는 **미확인** (이번에 읽은 페이지에 없음) |
| Resend (이메일) | 무료 월 3,000통, **하루 100통**, 도메인 3개 | 이메일 알림 후보. 사용자가 늘면 하루 100통이 병목 |

### 2.2 조합안 (제안)

| 안 | 구성 | 장점 | 위험 |
|---|---|---|---|
| **A (추천)** | 프런트: Next.js(웹앱) / 백엔드: Supabase(로그인·DB·Cron·Edge Function) / 호스팅: MVP는 Vercel Hobby | 직접 만들 부분이 적고 사용자별 분리를 DB가 담당. 무료로 시작 | 공개 출시 전 호스팅 비용 발생 가능. 1주 비활동 시 정지 |
| B | 프런트·API를 Cloudflare, DB는 Supabase | 호스팅 비상업 제한이 없을 가능성 | Cloudflare 무료의 상업 이용 조건 **미확인**, 구조가 한 단계 복잡 |
| C | 전부 직접 구축(자체 서버, 자체 인증) | 종속 없음 | 인증·삭제·보안을 직접 책임짐. 이해하며 개발하려는 목표에 비해 부담이 큼 |

"기술 스택은 오너가 결정"하므로 이 표는 비교용이다. A를 택해도 프런트 프레임워크(Next.js 등)는 별도로 정해야 한다.

### 2.3 알림 채널 (조사 범위: 제한적)

- **이메일(Resend):** 무료 한도 확인됨. 구현이 단순.
- **브라우저 푸시(Web Push):** 이번에 공식 자료를 확인하지 않았다. 모바일(특히 iPhone) 동작 조건은 **미확인** → 채택 전에 조사 필요.
- MVP 제안: 이메일 먼저, 푸시는 조사 후 추가.

## 3. 열린 위험 (결정 전에 확인할 것)

1. Supabase Cron이 무료 플랜에서 되는지, 일시정지 중에는 알림이 어떻게 되는지
2. Cloudflare 무료 플랜의 상업 이용 조건
3. Web Push의 모바일 지원 조건
4. 공개 서비스 시 호스팅 월 비용 (Vercel Pro는 좌석당 $20 — 팀이 아니어도 필요한지 약관 확인)

## 4. 첫 API 모델 후보

### 4.1 가격·데이터 정책 (공식 페이지 기준, 100만 토큰당)

| 후보 | Model ID (공식 표기) | 입력 | 출력 | 데이터 정책 (확인된 것) |
|---|---|---:|---:|---|
| Claude Haiku 5.5 | `claude-haiku-5-5` | $0.10 (프롬프트 10만 토큰 이하) | $0.50 | 상용 API 입력·출력은 **기본적으로 학습에 쓰지 않음**(Anthropic 고객센터 안내). 표준 보관 30일 또는 일부 모델·엔드포인트에서 ZDR. 유료 API 고객의 임의 삭제 요청은 불가(검색 요약). 약관 원문은 **미확인** |

| Gemini 3.5 Flash-Lite | `gemini-3.5-flash-lite` | $0.30 (유료) | $2.50 | 위와 동일 |
| Qwen | **미조사** | 미확인 | 미확인 | 미확인 |

- **Gemini 무료 등급에는 실제 사용자 일정을 보내면 안 된다.** 동의 기반 전송 원칙(`PRODUCT_SPEC.md` §2)과 충돌한다. 무료 등급은 합성(가짜) 평가 데이터에만 쓴다.
- Haiku/Sonnet 가격은 Anthropic 공식 가격 페이지, Gemini는 Google AI Studio 가격 페이지, OpenAI는 공식 문서·발표 페이지(검색 결과 요약) 기준이다. OpenAI 가격 페이지는 직접 열리지 않아 **결정 전 재확인**이 필요하다.
- 한국어 품질, 지연 시간, 구조화 출력 정확도는 **전부 미확인** — 평가로 채운다 (`MODEL_REGISTRY.md` §9.3).
- 투명성: 이 조사를 수행한 Claude Code는 Anthropic 모델이다. 가격 비교는 공식 표만 사용했고, 품질은 평가 전에는 판단하지 않았다.

### 4.2 추천 요청 1회 비용 추정

**가정(실제 측정 아님):** 요청 1회 = 입력 3,000 토큰(일정 요약 + 지시) + 출력 1,000 토큰, 하루 5회, 한 달 30일. 캐싱·배치 할인 제외.

| 후보 | 1회 | 1,000회 | 오너 1명 한 달(150회) |
|---|---:|---:|---:|
| Claude Haiku 5.5 | $0.0008 | $0.80 | $0.12 |
| GPT-5.4 nano | $0.0019 | $1.85 | $0.28 |
| Gemini 3.1 Flash-Lite (유료) | $0.0023 | $2.25 | $0.34 |
| Gemini 3.5 Flash-Lite (유료) | $0.0034 | $3.40 | $0.51 |
| GPT-5.4 mini | $0.0068 | $6.75 | $1.01 |
| Claude Sonnet 5.5 | $0.016 | $16.00 | $2.40 |

비용은 후보 모두 오너 혼자 쓰는 규모에서는 월 몇 달러 이하다. **비용보다 한국어 품질과 데이터 정책이 선택을 가른다.** 사용자가 늘면 1,000회당 비용 차이(최대 20배)가 커진다.

### 4.3 제안: 비교 평가 후 선택

1. 후보: Haiku 5.5, GPT-5.4 nano 또는 mini, Gemini Flash-Lite(유료) 중 3개
2. 같은 평가셋·프롬프트로 한국어 일정 이해, 추천 품질, 구조화 출력, **승인 없이 일정 변경을 시도하는지** 측정
3. 평가 입력은 **합성 데이터만** 사용 (실제 일정 금지)
4. 결과는 `MODEL_REGISTRY.md` §5에 기록, 오너가 선택
